# Мультимодальные рекомендации в контрастных товарных категориях: вклад текстов и изображений

Строим рекомендательную систему на датасете [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/) с использованием текстовой и визуальной модальностей. Анализируем, помогают ли контентные признаки на всей выборке и отдельно – для **холодных товаров** и пользователей с **короткой историей покупок**.

## Ключевые особенности

- **Абляции модальностей**: изучение вклада каждой модальности в качество рекомендаций
- **Гипотеза контрастирующих категорий**: ожидаем, что визуальная модальность даст аплифт на холодных айтемах категории *Amazon Fashion* и будет менее эффективна в категории *Groceries*
- **Сегментная валидация** качества модельных экспериментов на различных сегментах холодности айтемов и длин историй интеракций пользователей
- **Сравнение архитектур**: простой, но сильный одноэтапный бейзлайн, каскадная архитектура (ретривер на интеракциях + ретривер на контенте + ранкер) и обученная end-to-end нейросеть
- **Лайв-демо** рекомендации холодных айтемов: возможность добавить новый айтем в реалтайме на фронте и получить рекомендацию, включающую этот айтем (если он релевантен)

### Этап 1. EDA

**Сроки реализации:** 06.10 - 27.10

1. Знакомство с датасетом. Оценка качества данных: дубликаты, пропуски и выбросы
2. Определение логики предобработки датасета и построение ETL-пайплайна
3. Расчёт основных метрик очищенного датасета. Разреженность матрицы интеракций по категориям, распределение интеракций во времени, полнота информации по модальностям (для всех ли айтемов есть текстовые описания и картинки)
4. Установка логики расчёта целевой переменной (отзыв как имплицитный позитив)
5. Сравнение полноты контента по бакетам «холодности» айтемов (есть ли вообще у холодных айтемов картинки и тексты? Адекватные ли они?)
6. По итогам EDA выбор первой категории для проведения экспериментов (вторую подключим во втором семестре)

### Этап 2. Первые ML-модели

**Сроки реализации:** 27.10 - 27.11

1. Настройка MLflow и создание S3 бакета для команды. Все эксперименты логируем, артефакты и выборки сохраняем
2. Выбор протокола оценки (метрики и сплиты), построение пайплайна оценки качества моделей
3. Фиксирование вычислительного бюджета на тюнинг гиперпараметров для всех моделей и построение пайплайна в Optuna
4. Обучение неконтентных бейзлайнов (TopPopular, iALS, ItemKNN)
5. Выбор энкодера модальностей (он будет использоваться в лайв-демо, важно сравнить производительность). Использование его для получения эмбеддингов текстов и картинок
6. Обучение контентного бейзлайна (ItemKNN-CBF) в трёх вариациях:
   - интеракции + тексты
   - интеракции + картинки
   - интеракции + обе модальности
7. Исследование качества и производительности на разных подвыборках итогового множества рекомендаций (в зависимости от бакета «холодности» айтема и длины истории интеракций пользователя)
8. Подготовка первичного вывода о полезности контентных фичей: в каких кейсах помогают и какие конкретно модальности
9. Выбор лучшего эксперимента, добавление его в реестр моделей MLflow

### Этап 4. Улучшение бейзлайна

**Сроки реализации:** 15.01 - 15.03

1. Объединение контентного и неконтентного бейзлайнов, переиспользование полученного ансамбля в качестве кандидатогенератора
2. Добавление второй категории в обучающую выборку с переобучением бейзлайнов на ней
3. Модификация пайплайна оценки качества для новой каскадной архитектуры (сплит на трейн ретривера, трейн ранкера и тест)
4. Feature engineering для ранкера в четыре группы фичей:
   - только ID (скоры ретриверов, популярность, инфа о пользователе и прочее)
   - ID + текст
   - ID + картинки
   - ID + оба
5. Разработка ранкера: логрег на скорах ретриверов и CatBoost с ранжирующим лоссом. CatBoost строим также в четырёх вариантах
6. Продолжение оценки полезности модальностей, начатой на предыдущем этапе: опирается ли вообще ранкер на модальности, и если да, то помогает ли это ему меньше ошибаться
7. Выбор лучшей модели, добавление её в реестр моделей MLflow

### Этап 5. Нейронка

**Сроки реализации:** 15.03 - 05.05

1. Обучение двубашенной нейросети (айтемная башня с контентными эмбедами) в четырёх вариациях
2. Обучение трансформера (SASRec) в четырёх вариациях
3. Обучение модели на семантических айдишниках (*задача со звёздочкой*, если будет время. Решение по реализации примем после этапа 4)
4. Сравнение качества рекомендаций нейросетевых решений с классическим ML

> Вариации: только интеракции; интеракции + тексты; интеракции + картинки; всё сразу
